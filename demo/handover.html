v1.0 · 28 Sep 2026

Paste once.
Every AI answers.
See where they disagree.

A local tool that sends one job post, job description or code change to several AI models at once, then shows their verdicts side by side with a short list of where they agree and where they don't. It runs on one PC. Nothing is hosted, and the reviewers can answer but cannot act.

01 — What it does
01 — One question, independent answers

Each model answers alone, then one compares them blind

PASTEFrom the web page, from a Claude Code chat ("ask all"), or from the command line. All three run the same engine.
ONE PROMPTThe task's instructions plus the input. Job tasks also carry the owner's verified fact base, the only allowed source for claims about him.
IN PARALLELEvery enabled model gets the identical prompt at the same moment. A run takes about a minute.
BLIND COMPARISONOne model reads the answers labelled A and B, never by name, and writes the bottom line, agreements, disagreements, and what only one caught.
THE PAGEA verdict per model in colour, whether they agree, then every section side by side. Each run is saved as a folder.
02 — Three tasks, each with a fixed answer shape

A fixed shape is what makes answers line up

JOB POSTFreelance briefs. Verdict: Bid, Bid with care, or Skip. Then diagnostics, pain points, positioning, quickest proof of concept, fit, open questions.
JOB FITFull-time roles. Verdict: Apply, Apply after fixing gaps, or Skip. Each must-have marked Met, Partly or Missing with the fact that shows it.
CODE REVIEWPasted code or a project's uncommitted changes. Verdict: No real problems, Minor fixes, or Must fix. Each finding names a case that triggers it.
FOLLOW-UPSA question on any result goes to every model with the whole thread, so each can answer the other's earlier points.

02 — How it stays fair and safe
03 — The same question for every model

No model sees more than the others

Models run from an empty folder outside the owner's workspace, so no project files are picked up. Claude's hooks are switched off, so its memory system cannot feed it saved notes the other model never sees. The one known difference is stated on the last page: Claude still reads the owner's global style rules.

04 — Reviewers answer, they never act

Checked by asking the reviewer, not by reading the settings

Claude runs with no tools and no connected apps: asked to list what it can call, it answers "None." In Gemini's case, reading a file on the PC and opening a web page are both refused automatically. Gemini can still run a web search; when any tool runs, a warning sits at the top of its answer.

05 — Pasted text is material, not orders

A planted instruction is quoted back, not followed

Every task tells each model that the pasted input is data to analyse. Any line addressed to an AI is listed under "Suspicious instructions in the input", and the page turns that into a red banner above the verdicts.

06 — Only this PC can reach it

A local page, not a website

The page server listens on this PC only. It refuses requests from other websites, form posts, disguised addresses, any task outside the three, and any file it does not know by name. It stores no keys: Claude uses the owner's subscription and Gemini a Google sign-in.

07 — Three defects found while building it

Each one looked fine from the outside

CONNECTED APPS"No tools" still left every connected app callable: email, file storage with delete and share, team chat with send, automation writes. Found by asking the reviewer to list its tools. Fixed with a switch that loads none; the same question now returns "None."
A ROUTE CLOSEDGoogle stopped serving free users through Gemini's command-line tool on 18 Jun 2026; a real sign-in on 28 Sep was refused. Replaced by Antigravity CLI through one small adapter file. Nothing else changed.
A WINDOW FLASHEDA console window appeared every 15 minutes or so; Antigravity's self-updater log matched the times. The first fix set its off-switch to "1" and failed its own check: the updater ran again. With "true" it logs "auto-update disabled", and a hidden update runs once a day instead.

04 — How to run it
09 — Opening it

A bookmark that works after every restart

BOOKMARKhttp://127.0.0.1:8770. The server starts hidden at login from the Windows Startup folder.
DESKTOP ICON"Ask All" starts the server if it is not running, then opens the page.
FROM A CHATIn a Claude Code chat on the same PC, paste the post and add "ask all".
10 — Using it

Read it in the order it is laid out

1 · ASKPick a task, paste, press Ask (or Ctrl+Enter). For a code review, a project folder works instead of pasting.
2 · GLANCEThe verdict board: one colour per model and whether they agree. Green go, amber careful, red stop.
3 · SKIMThe bottom line, then the disagreements. That is where the decision is.
4 · DIGSections side by side; long text opens with "Show more". Ask a follow-up in the box below.
11 — Changing it

A new model is one entry; a new task is one file

A model is any command that reads the prompt and prints an answer: one entry in models.toml. A task is one file in tasks/ plus one line in the page's allow-list. Every run is kept in runs/. Detail: README.md.

05 — Limits & ownership
12 — Deliberate limits

What it will not do

ACTNo reviewer can send, change or delete anything. They read a prompt and answer.
PICK A WINNERIt shows where the models agree and disagree. The decision stays with the person reading it.
LEAVE THE PCThe page is reachable from this PC only. No part of it is hosted.
13 — Known gaps, stated

Not done yet

NO TEST SUITEThe proof is saved runs and repeatable probes, not unit tests.
GEMINI'S FREE LIMITNot published by Google. A run that hits it shows FAILED with the reason.
STYLE RULESClaude reads the owner's global style rules; Gemini has none. Tone can differ for that reason.
SAME-MOMENT ANSWERSIn a follow-up, each model sees the other's earlier answers, not its reply to the current question.
14 — Scope and ownership

One PC, one owner, no paying client

Python standard library and one plain web page: no framework, nothing to install beyond the two AI command-line tools. No key or password is stored anywhere in the tool. Two more models are listed as switched-off examples and have not been tested.
